
# wBMS Release Changelog (Safety MCU)


---------------------------------------------------------------
## v3.8.3 STABLE

- Added compatibility with four chargers (different CAN IDs) 
  in "TC Charger" CAN protocol.
- Added data on Battery Pack data reporting CAN bus protocol:
   - Add Analog Input voltage values (0x5D0 + BMU ID).
   - Add current sensor maximum and minimum current values 
     (0x540 + BMU ID).
   - Add maximum and minimum balancing check voltage (0x580 + 
     BMU ID).
- Added CAN bus incompatibility with older FW versions due to 
  new CAN data.
- Added new output trigger option: "BMU temperature range".
- Added two new heating pads operating modes:
  - "CONNECTED with charging current".
  - "CONNECTED with discharging current".
- Improved robustness of General Purpose Outputs (GPO) 
  diagnostics.
- Improved CMU temperature measurement circuitry monitoring.
- Improved communication robustness when uploading BMU
  settings.
- "Sleep delay (post-run)" time not applied after a BMU PoR 
  event.
- Bugfix: solved problem of not reaching 100% SoC when 
  "CHARGED/DISCHARGED trigger by SoC" is enabled.
- Bugfix: solved problem with HVIL detection (only affecting 
  RMX and MX-PRO v2.X BMUs).
- Bugfix: solved problem with J1939 SPN8413 (HVESS High-Voltage 
  Bus Connection Status) wrong "Connection in Process" status 
  reported sometimes.
- Bugfix: solved problem not reporting all balancing status in 
  Battery Pack Extended data reporting CAN bus protocol when 
  there are more than 576 cells.
- Bugfix: solved wrong current sensor OS warning DTC reported 
  when using multiple current sensors.
- Bugfix: solved problem with "Consumption for SoC 
  compensation" when using multiple current sensors.

---------------------------------------------------------------
## v3.8.2 BETA

- Added "Relaxation current" parameter to improve SoC OCV 
  calibration.
- Added "Maximum current when DISCONNECTED" paramenter. The BMS 
  can allow current flow when contactors are open.
- Added compatibility with JY1000 IMD sensor.
- Added BMU external temperature sensors "Beta" and "Nominal 
  resistance" configuration.
- Added new heating pads mode "Only when CONNECTED".
- Added coin cell battery CR2032 voltage measurement for 
  wBMS-HX BMU.
- Added CAN bus BMU Main data reporting enable parameter. When 
  disabled the CANBus BMU Main data reporting messages are not 
  sent and the Duplicated Primary error is disabled.
- Added CAN bus J1939 configuration parameters, one for 
  enabling the Battery System messages and the other for 
  enabling Battery Pack messages.
- Added diagnostics for General Purpose Outputs (GPO) 9 and 10.
- Improved temperature value reporting when NTC open wires or 
  short circuit occurs.
- Bugfix: solved incorrect data reporting of individual current 
  sensor measurements.
- Bugfix: solved possible false errors with redundant current
  sensor mismatch.

---------------------------------------------------------------
## v3.8.1 BETA

- Updated wBMS-Toolkit Inputs/Outputs configuration user 
  interface. All inputs and outputs of the BMU are configurable.
- Added all inputs and outputs status in BMU CAN bus protocol 
  (0x5D0 + BMU ID) for BMU-MX Pro and BMU-HX.
- Added all outputs CAN interlocks in BMU CAN bus protocol 
  actuation message (0x200 + BMU ID) for BMU-MX Pro and BMU-HX.
- Added up to 4 analog current sensor measurements on compatible 
  hardware for monitoring multiple strings.
- Added the possiblity of closing contactors during the "Sleep 
  delay (post-run)". Contactors connection follows the Start 
  signal request instead of forcing a disconnection during this
  stage.
- Added automatic timestamp update through Internet in BMU-HX.
- Removed number of CMUs limitation on CMU Link for BMU-MX Pro 
  and BMU-HX. These models accept all CMU architectures up to 48
  CMUs and now support monitoring up to 864 cells and 432 cell
  temperatures.
- Improved NTC open-wire detection in HX CMU16.
- Improved J1939 actuation message processing when transmitted 
  at 50 Hz.
- Bugfix: solved problem with BMU incorrectly reporting 0A 
  setpoint (stop charge/discharge flags) after the end of
  charge/discharge when using "CV stage controller" as "wBMS 
  (through current setpoint)".
- Bugfix: solved J1939 actuation message CRC calculation error 
  when any unused bit (no SPN associated) is set to 1.
